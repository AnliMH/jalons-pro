📖 Comment mettre à jour l'app ?
▼
L'app est hébergée sur GitHub Pages → anlimh.github.io/jalons-pro
🔄 Pour mettre à jour l'app :
1 Télécharge le nouveau fichier depuis Claude et renomme-le index.html
2 Va sur github.com/anlimh/jalons-pro
3 Glisse le nouveau index.html directement sur la page du dépôt
4 Clique "Commit changes" → attends ~1 minute → l'app est à jour ✅
💡 Tes données Supabase sont séparées du code — une mise à jour n'efface jamais tes affaires.
